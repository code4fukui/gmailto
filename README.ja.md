# gmailto

Gmailの新規作成画面に内容が事前入力されたリンクを生成する、シンプルなシングルページWebアプリです。

このツールは、通常の`mailto:`リンクではなく、Gmailの作成インターフェースへの直接URLを生成します。

## デモ

[https://code4fukui.github.io/gmailto/](https://code4fukui.github.io/gmailto/)

## スクリーンショット

ユーザーインターフェースはすっきりと分かりやすく、To、CC、BCC、Subject（件名）の入力フィールドと、Body（本文）用のテキストエリアを備えています。生成されたリンクは、入力フォームの下でリアルタイムに更新されます。

## 機能

- **動的なリンク生成:** 入力に合わせてリアルタイムで更新される、Gmail作成ウィンドウへの直接リンクを生成します。
- **完全なメール作成:** `To`、`CC`、`BCC`、`Subject`、`Body`の各フィールドをサポートしています。
- **依存関係ゼロ:** ブラウザ上で完全に動作する、スタンドアロンの単一HTMLファイルです。
- **シンプルかつ高速:** メールリンクを素早く作成するための、ミニマリストなインターフェースです。

## 使い方

1. [デモページ](https://code4fukui.github.io/gmailto/)を開きます。
2. 任意のメールフィールド（To、CC、BCC、Subject、Body）を入力します。
3. ページ下部の「gmailto link」をクリックします。
4. 新しいタブが開き、入力内容が事前に入力されたGmailの作成ウィンドウが表示されます。
